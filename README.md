# buildsync.ai

This is the official repo of buildsync.ai

The public marketing website of **BuildSync AI**, an AI workspace for engineering plans. Only the **homepage** (`/`) is built so far.

## Development

Next.js (App Router) marketing site. Homepage lives in `app/(marketing)/page.tsx`.

```
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck  # TypeScript check only
```

Pricing slots read from `lib/site.ts` (`{{PRICE}}` until final). The workspace
previews are SVG stand-ins (`components/WorkspaceMock.tsx`) until the real
workspace screenshots / `<Workspace demo />` are available.

## What every file is for

Every source file starts with a header comment that says who wrote it, what it
does, what it is for, where it is used and what to check if it breaks.

| File | What it does |
|---|---|
| `app/layout.tsx` | Root layout: `<html>`/`<body>`, global CSS, Google Fonts, default page title and share-card metadata |
| `app/(marketing)/layout.tsx` | Shared header + footer for all marketing pages (the folder name in parentheses is not part of the URL) |
| `app/(marketing)/page.tsx` | The homepage: puts Blocks 2-15 of the spec in order |
| `app/globals.css` | The one stylesheet: design tokens, every section, responsive rules |
| `components/Header.tsx` | Announcement bar, sticky header, mega-menus, search overlay, mobile menu |
| `components/Hero.tsx` | Hero section: headline, email capture, auto-cycling workspace preview |
| `components/Carousel.tsx` | Feature card carousel (8 cards) |
| `components/Showcase.tsx` | Dark tabbed product showcase |
| `components/Compare.tsx` | Competitor compare table (competitor cells stay `[verify]` until checked) |
| `components/Pricing.tsx` | Monthly/Yearly toggle and the four plan cards |
| `components/Newsletter.tsx` | "Stay in the know" email box (not connected to an email service yet) |
| `components/Footer.tsx` | Site footer |
| `components/Icon.tsx` | Built-in icon set and the logo |
| `components/WorkspaceMock.tsx` | SVG stand-in for the real workspace screenshots |
| `lib/site.ts` | All shared content: menus, features, disciplines, compare rows, prices |
| `next.config.mjs` | Next.js settings |
| `tsconfig.json` | TypeScript settings |
| `package.json` / `package-lock.json` | Dependencies and scripts (the lock file is generated by npm; do not edit by hand) |
| `.gitignore` | Files Git must not track |
| `CLAUDE.md` | Working rules for AI coding sessions in this repository |

## Not built yet

and the other pages in the spec's site map show a 404 until those pages are built.
